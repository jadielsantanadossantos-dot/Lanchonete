Configuração Pix

Pix Automático (Banco) Recomendado: fallback manual

Quando configurado, o sistema gera cobrança dinâmica e confirma o Pix via webhook do banco. Se desativado ou falhar, o Pix estático + botão WhatsApp continuam funcionando.

Lista fixa — cole as credenciais abaixo. Nenhum certificado precisa ser enviado, apenas cole.
Deixe vazio para usar a Chave Pix acima.
Tempo para o cliente pagar antes de expirar. Padrão 3600 (1h).
Como configurar: 1) Selecione o banco → 2) Cole Client ID/Secret do painel do banco → 3) Salve → 4) Copie a URL do webhook e cole no painel do banco → 5) Clique em Testar Conexão.
Dica: Banco Inter/EFI exigem app criado no portal do banco. Mercado Pago/Pagar.me usam apenas Client ID/Secret.
